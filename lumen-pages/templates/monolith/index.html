Four weeks from brief to master file

Most jobs run on the same calendar. You see something every Friday, and the thing you see is the thing you get, one stage further on.

  1. Week 1

    Blockout

    Grey geometry, camera angles, the one lighting idea. Enough to argue about composition before anyone spends money on materials.

  2. Week 2

    Material and light

    Surfaces built from reference you send me, or from the actual object posted to the studio. Light set up like a product shoot: one key, one fill, one edge.

  3. Week 3

    Motion, if any

    Loops are timed to the beat of wherever they will play. Nothing moves that would not move in real life.

  4. Week 4

    Render and grade

    Final frames at delivery size plus one size up. Graded in ACES, delivered with the scene file so your next studio can pick it up.
