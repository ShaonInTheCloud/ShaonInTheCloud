Install and sign in

  1. Download on your phone

    Open this portal on an Android phone, then tap Download Android APK.

  2. Install the APK

    Open the downloaded file. If Android requests it, allow installation from that browser or file manager, then tap Install. Turn that installation permission off again afterward.

  3. Use your SafeNest account

    Open SafeNest, tap the Account icon, and sign in with the same confirmed email and password you use here.

Protection activation is not available yet

You can install the app and sign in. This build requires a verified paid period to start protection; checkout and payment activation are not connected yet. Saving a profile or logging in does not start blocking.

After activation becomes available, follow the app's permission and consent screens and test normal browsing before relying on protection. This development build must leave Android's “Block connections without VPN” setting off.

If Android cannot install the update

An existing SafeNest installation needs an update signed with the same certificate. If Android reports a conflicting package or signature, keep your existing installation and request a matching update.

Delete my SafeNest account

This permanently deletes your account, profile and server protection entitlement. It does not uninstall the app or immediately erase local device lists. If billing becomes active, cancel renewal through your payment provider separately.
