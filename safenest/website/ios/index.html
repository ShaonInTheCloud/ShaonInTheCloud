Install it

1. Download

Open this page in Safari on the iPhone and tap Download the SafeNest profile, then Allow. If you got the file another way, open it from the Files app.

2. Install

Open Settings. Tap Profile Downloaded near the top (or General › VPN & Device Management), choose SafeNest gambling blocker, tap Install, enter your passcode and tap Install again. iPhone labels it "Not verified" because it is a test profile.

3. Turn it on

Go to Settings › General › VPN & Device Management › DNS and make sure SafeNest DNS filter is selected. Then try a betting site in Safari — it should fail to load.

Honest limits

Can it be switched off?

Yes. On a personal iPhone, Apple lets the owner remove any profile in Settings. A real lock needs Apple's Screen Time API in the SafeNest iPhone app, which is being built next.

Does a VPN app get around it?

Usually yes. When a VPN app such as 1.1.1.1 is connected, iPhone uses the VPN's DNS instead. SafeNest blocks the common encrypted-DNS servers by name, but it cannot stop a VPN app on iPhone.

What happens to a blocked site?

The lookup is answered with an empty address, so the page simply does not load. There is no SafeNest page in between yet.

Is my browsing history uploaded?

The filter sees each name your phone looks up — that is how DNS works — but SafeNest does not log or store them. Names that are not on the blocklist are passed to Cloudflare's or Google's public DNS to get the real address.

How do I remove it?

Settings › General › VPN & Device Management › SafeNest gambling blocker › Remove Profile.
